# Phase 10.1 — Transformer Error Analysis

Copy `scripts/phase10_1_error_analysis.py` into the project `scripts` folder.

Run:
```powershell
python -u scripts\phase10_1_error_analysis.py
```

It reads the completed Phase 10 predictions and produces confusion matrix, class error rates, error types, domain performance, misclassified reviews, and a summary. It does not retrain the model.
